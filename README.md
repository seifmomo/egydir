# EGYDIR — إيجي داير | دليل الشركات والمصانع المصرية

إعادة تصميم شاملة وفعّالة للموقع العربي القديم **EGYDIR** (B2B Directory) بهوية عصرية **متميزة ومفعمة بالحياة** على نمط منصات SaaS الحديثة، مع دعم كامل للاتجاه **RTL** (من اليمين لليسار).

## ✨ المميزات

- **هوية بصرية مميزة** — كحلي داكن `#1A365D` + تركوازي `#319795` + **اكسنت ذهبي** `#F59E0B` + خلفية بيج `#F7FAFC`، مع تدرجات وأنيميشن حديثة
- **دعم RTL كامل** للغة العربية مع خطوط **Tajawal / Cairo** واستخدام الخصائص المنطقية (`start/end`)
- **هيرو بعمودين** — العنوان والبحث متصرفاً، وإلى جانبهما **معاينة نافذة التطبيق**: نافذة متصفح تحتوي بطاقات شركات حقيقية (شعارات + تقييمات) بدون أي فوضى أو تداخل
- **هيدر ثابت** مع خط متدرج علوي، بحث مركزي، وأزرار دخول بألوان مميزة
- **صفحة رئيسية غنية** — هيرو تفاعلي، شبكة 12 قطاعاً **بلون مميز لكل قطاع وعدد حقيقي للنتائج**، قسم «لماذا إيجي داير؟»، شركات مميزة ببطاقات متطورة، وقسم CTA ختامي
- **صفحة دليل الشركات** — بانر متدرج يعرض اسم القطاع بالعربية مع **ختم «قائمة موثّقة»**، فلاتر جانبية قابلة للطي (نوع النشاط، القطاع، المدينة، التوثيق، التقييم)، ترتيب فوري، وشرائح البحث النشط
- **بحث ذكي متعدد الكلمات** — تقسيم البحث إلى كلمات (مع التعامل مع «و» العربية) بحيث يعرض نتائج مناسبة لكل استعلام
- **فلاتر نشاط فعّالة** — تصنيع تلقائي لمصانع/مستوردين/مصدرين/شركات، بحيث تعمل روابط القائمة العلوية فعلياً
- **شريط الرعاة** — استعراض تلقائي **راعي واحد في كل مرة** بحلقة لا نهائية، مع مؤشر تقدم وقائمة الرعاة كلهم (مرة واحدة)
- **صفحة الملف الشخصي** — بانر متدرج مع شعار الشركة، شارة **موثّق**، تبويبات **عن الشركة / المنتجات / بيانات التواصل**، وشركات مشابهة
- **فوتر داكن** مع بانر «أضف شركتك مجاناً» وخط متدرج
- **معالجة آمنة للشعارات** — بديل تلقائي (أول حرف بتدرج لوني) عند فشل تحميل أي صورة شعار

## 🧠 البيانات

البيانات المدمجة **مبنية على بيانات حقيقية من الموقع القديم** `www.egydir.com`:

- **38 قطاعاً صناعياً** بالمعرّفات الأصلية
- **16 مدينة** صناعية
- **~48 شركة حقيقية** (الاسم، الهاتف، البريد، الموقع، المسؤول، النشاط، وشعار حقيقي) مثل: الأهرام للتجارة والصناعة، الشروق للتصدير، أكتوبر فارما، الهيئة العربية للتصنيع ABD، يورباك، وغيرها
- **~200 شركة تجريبية إضافية** مولّدة تلقائياً (بذرة ثابتة) خصيصاً لملء كل قطاع وفلتر وبحث بنتائج واقعية
- **الرعاة الرسميون** الأصليون

> المصدر `src/data.js` + `src/demo-data.js` — يمكن استبدال/توسيع القائمة بسهولة من تصدير قاعدة بيانات الموقع القديم.

## 🚀 التشغيل

يتطلب **Node.js 18+** و **npm**.

```bash
# 1) تثبيت الاعتماديات
npm install

# 2) تشغيل خادم التطوير
npm run dev

# 3) فتح المتصفح على العنوان المعروض
#    (التطبيق يعمل تحت المسار /egydir/ — مثال http://localhost:5173/egydir/)
```

> ملاحظة: عند ظهور تنبيه `npm warn allow-scripts` أثناء التثبيت، نفّذ:
> `npm approve-scripts --all`
> (يُعتمد `esbuild` اللازم لبناء Vite).

### البناء للإنتاج

```bash
npm run build      # توليد مجلد dist/
npm run preview    # معاينة البناء النهائي محلياً
```

## 🚀 النشر على GitHub Pages

```bash
npm run deploy
```

يقوم الأمر بـ:

1. بناء التطبيق مع المسار الجذري `/egydir/`
2. إضافة ملفات `.nojekyll` و `404.html` (لإصلاح الروابط الداخلية عند تحديث الصفحة)
3. نشر مخرجات `dist/` إلى فرع `gh-pages`

يُفعّل الموقع تلقائياً على `https://<user>.github.io/egydir/`. لإعادة النشر بعد أي تعديل، أعد تشغيل نفس الأمر.
