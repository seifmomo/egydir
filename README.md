# EGYDIR — إيجي داير | دليل الشركات والمصانع المصرية

إعادة تصميم شاملة وفعّالة للموقع العربي القديم **EGYDIR** (B2B Directory) بهوية عصرية أنيقة على نمط منصات SaaS والمواقع المؤسسية، مع دعم كامل للاتجاه **RTL** (من اليمين لليسار).

![Stack](https://img.shields.io/badge/React-18-blue) ![Tailwind](https://img.shields.io/badge/Tailwind%20CSS-4-38bdf8) ![Vite](https://img.shields.io/badge/Vite-6-646cff)

---

## ✨ المميزات

- **تصميم حديث ونظيف** — هوية بصرية مؤسسية: كحلي داكن `#1A365D` + تركوازي `#319795` + خلفية بيج `#F7FAFC` + نص `#2D3748`
- **دعم RTL كامل** للغة العربية مع خطوط **Tajawal / Cairo**
- **هيدر ثابت** مع شعار في أقصى اليمين، شريط بحث على شكل حبّة، وأزرار تسجيل دخول بحواف أنيقة
- **صفحة رئيسية** — هيرو متميز، شبكة قطاعات بأيقونات خطية، شركات مميزة ببطاقات موحّدة، شريط رعاة متحرك (رمادي في الملون عند التمرير)
- **صفحة دليل الشركات** — فلاتر جانبية قابلة للطي (قطاعات، مدن، توثيق، تقييم)، بحث وترتيب فوري، شبكة بطاقات متجاوبة
- **صفحة الملف الشخصي للشركة** — بانر نظيف مع شعار الشركة في حاوية بيضاء متداخلة (نمط LinkedIn)، شارة **موثّق** زرقاء، تبويبات: **عن الشركة / المنتجات / بيانات التواصل**، وشبكة منتجات أنيقة
- **فوتر متعدد الأعمدة** بخلفية كحلية داكنة وشعار مصغّر

## 🧠 البيانات

البيانات الواردة **حقيقية ومأخوذة من الموقع القديم** `www.egydir.com`:

- **38 قطاعاً صناعياً** بالمعرّفات الأصلية
- **16 مدينة** صناعية
- **~48 شركة حقيقية** (الاسم، الهاتف، البريد، الموقع، المسؤول، النشاط، وشعار حقيقي) مثل: الأهرام للتجارة والصناعة، الشروق للتصدير، أكتوبر فارما، الهيئة العربية للتصنيع ABD، يورباك، وغيرها
- **الرعاة الرسميون** الأصليون

> المصدر `src/data.js` — يمكن استبدال/توسيع القائمة بسهولة من تصدير قاعدة بيانات الموقع القديم.

## 🚀 التشغيل

يتطلب **Node.js 18+** و **npm**.

```bash
# 1) تثبيت الاعتماديات
npm install

# 2) تشغيل خادم التطوير
npm run dev

# 3) فتح المتصفح على العنوان المعروض (افتراضياً http://localhost:5173)
```

### البناء للإنتاج

```bash
npm run build      # توليد مجلد dist/
npm run preview    # معاينة البناء النهائي محلياً
```
